# Médias

Déposer les visuels et les médias autorisés dans ce dossier. Les illustrations V5 sont des SVG intégrés au HTML ; aucune image externe n’est requise. Le sous-dossier `interviews/` est réservé aux futures vignettes et vidéos validées. Ne jamais déposer de CV, de données de candidats ou de secrets dans le dépôt public.
